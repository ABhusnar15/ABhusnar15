## 👨‍💻 About Me

I am an ambitious **Java Backend & Full-Stack Developer** pursuing my **Master of Computer Applications (MCA)**, backed by a strong academic foundation from a **BSc in Computer Science**. 

My core focus is designing **scalable microservices**, implementing **event-driven pipelines with Apache Kafka**, engineering **resilient RESTful APIs**, and applying clean architecture and SOLID principles to produce maintainable, high-impact software.

- 🎓 **Academic Background**: MCA Candidate with a Bachelor of Science (BSc) in Computer Science.
- ⚙️ **Backend Engineering**: Specialized in **Java 17+**, **Spring Boot 3**, **Spring Data JPA**, **Hibernate**, and **Node.js/Express**.
- 📡 **Event-Driven & Messaging**: Hands-on implementation of asynchronous event streaming with **Apache Kafka**.
- 📱 **Cross-Platform & Web**: Experienced in **Kotlin & Jetpack Compose** (Android) and modern **React 18** web applications.
- 🧮 **Algorithmic Thinking**: Deep interest in greedy algorithms, optimization problems, security monitoring systems, and data structures.
- 🚀 **Industry Simulation**: Built **Midas Core** as part of the **JPMorgan Chase & Co.** Advanced Software Engineering Virtual Experience.
